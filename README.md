# Spring PetClinic Learning Project

This repository is a from-scratch implementation of a Spring PetClinic-style application.

The project will be built gradually so that each important Java and Spring concept can be understood while the application moves forward through meaningful engineering milestones.

## Learning Objective

The goal is to learn how an empty project evolves into a structured Java and Spring Boot web application.

The roadmap covers Java, Maven, Spring Boot, Spring MVC, Spring Data JPA, Thymeleaf, validation, databases, testing, concurrency, observability, CI/CD, and deployment.

## Build Approach

Before each new batch, the real repository is inspected and the next milestone is selected from the roadmap.
