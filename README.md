# Spring PetClinic Learning Project

This repository is a from-scratch implementation of a Spring PetClinic-style application.

The project will be built gradually so that each important Java and Spring concept can be understood before the next concept is introduced.

<!-- Batch - 001 Part 2: Define the long-term learning objective. -->
## Learning Objective

The goal is to learn how an empty project evolves into a structured Java and Spring Boot web application.

Future topics will include Java, Maven, Spring Boot, Spring MVC, Spring Data JPA, Thymeleaf, validation, databases, and testing.

## Build Approach

The project will be built through small hands-on steps.
