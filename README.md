# Spring PetClinic Learning Project

This repository is a from-scratch implementation of a Spring PetClinic-style application. The project is being built gradually for learning, with each feature introduced in small steps. Java and Spring Boot will be used as the application develops. No working application exists yet.

## Learning Objective

The goal is to learn how a Java web application evolves from an empty repository into a structured Spring Boot application. Concepts will eventually include Java, Maven, Spring Boot, Spring MVC, Spring Data JPA, Thymeleaf, validation, databases, and testing. This is only a roadmap.

## Build Approach

The application will be built incrementally. Each learning step introduces a small concept or code change so that the reason for every important part of the application can be understood.
